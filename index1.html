AttendX - Smart Attendance System

A web-based attendance system designed to eliminate proxy attendance using QR authentication, device fingerprinting, and GPS-based validation.

Problem Statement

Traditional attendance systems are time-consuming and prone to proxy attendance. Manual roll calls reduce lecture efficiency and lack proper tracking mechanisms.

Existing Systems

Manual attendance, RFID and biometric systems either allow proxy or require expensive hardware.

Innovation

AttendX uses QR + device fingerprint + GPS + database validation to prevent proxy attendance.

System Methodology

Student data + QR tokens

QR Scan → Validation → Database

VIEW DEMO

Results

Attendance reduced from ~5 minutes to under 30 seconds while minimizing proxy attendance.
